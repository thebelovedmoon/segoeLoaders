I. scope of this project

this project harnesses the complexity of Unicode's Private Use Areas (PUAs) and vanilla frontend in order to bring the familiar Windows Spinners to life -- beyond the boot screen and other loading elements applicable.

specifically, this project aims to tackle the following objectives:

  • bring the true-to-code nature of Windows spinners beyond the boot sequence -- severely limiting its DOM overhead
  • enable visual customization for a personalized look
  • emphasis on embeddability -- make the spinners run alongside any web project

II. the embeddability statute

this project was initially a simple web demonstration of how Segoe Boot Semilight and Private Use Areas intertwine on boot, in the same way Segoe MDL2 Assets and Segoe Fluent Icons do in a normal Windows session.

however, with the need to utilize this spinner for the modern web, this statute is enforced in order to ensure the legitimate usage of this tool.

a. appropriate places

the embeds may be used solely in places where spinners are genuinely applicable, such as loading interfaces and interactive elements.

there is no restriction in utilization of the embeds; however, the developer must ensure that the utilization is acted in good faith and does not compromise the end user's experience.

b. psychological exploitation

there have been reports of replicated spinners being used for instances that invoke psychological exploitation -- even if it's a mere demonstration or simulation.

in extreme cases, such exploitations lead to rampant harm for end-users -- as demonstrated by Big Head with their fake-update infostealer and ransomware in 2023.

c. enforcement

in conjunction, the enforcing portion of this statute is that none of the embeds must NOT bode harm on the end-user; and that the developer MUST acknowledge the risk and responsibility in utilizing this embed for their web projects.


III. stance on "fake update" websites

there are a number of "fake update" simulations and its equivalents -- like fakeupdate.net -- that loosely mimic the legitimate Windows Update screens. even though they are harmless, they still constitute to psychological exploitation as briefly explained in section II-b.

as such, this project discourages the use of this embed for such nefarious purposes that exploit such behaviors. enforcement is indicated in section II-c.


IV. third-party notices

portions of this project make use of third-party assets in order to enhance this experience, in which some of them may be proprietary.

we have utilized such assets -- in good faith -- in hopes to maintain accuracy as the proprietors intended.

if a developer wishes to put it in a project, one must be sure to add the contents of both LICENSE and THIRDPARTY.txt in a separate THIRDPARTY file or anywhere in their website that publicly states the license designations. such files are easily accessed from our GitHub repository.
